## 🚀 Descrição do projeto:
- Autenticação de usuários (registro e login com JWT);
- Gerenciamento de produtos (adicionar e listar);
- Criação de pedidos (Para usuários autenticados);
- Fila de processamento de pedidos usando Redis;

## 🛠 Tecnologias Utilizadas:
- Node.js 
- GraphQL com Apollo Server
- Prisma ORM
- MongoDB
- Redis (fila de pedidos)
- JSONwebtoken (autenticação JWT)
